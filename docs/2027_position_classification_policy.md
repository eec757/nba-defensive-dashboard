# 2026–27 Position Classification Policy

Decision confirmed by dashboard owner on 2026-10-25.

## Primary dashboard position

Use independently verified **season roster positions** (PG, SG, SF, PF, C) as the primary classification for opponent player-game defensive comparisons. The position must be tied to the player and the relevant season, with exact NBA/Basketball-Reference identity corroboration. Do not infer a season position from a game box-score role.

## Separate game-specific role view

Game-specific position/role observations may be collected in a **separate**, explicitly labeled view only when a reliable per-game source and game/player identifiers are verified. Keep the source, observation date, game ID, NBA player ID, and original position designation. Never silently substitute a game-specific SG for a season-roster PG or merge the two classification methods into one coverage denominator.

## Publication safeguards

- Keep the 95% leaguewide, defending-team, and conservative team-position coverage requirements unchanged.
- Preserve nonzero verified opponent-game observations for every published defending-team/position combination.
- Missing season position evidence remains unknown; user manual identity review is not independent source corroboration.
- The Portland–Phoenix game `0022600092` is a source-position disagreement example, not permission to relabel players.
- The secondary game-specific view remains unpublished until it has a verified source, separate audit, and explicit readiness review.
- No automatic human approval, crosswalk edits, draft PR merge, or production deployment from this policy.
